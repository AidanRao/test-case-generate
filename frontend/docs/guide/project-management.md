# 项目管理

主页是项目管理入口；开启“显示知识库”时，也会展示本地知识库入口和概览。可在[系统设置](./settings#界面显示)中调整是否显示知识库。项目列表显示项目名称、项目编号、一级功能数量和二级需求数量。

## 创建项目

点击左侧 **新建项目**，按页面提示填写项目基础信息和功能需求。

项目编号用于区分项目，填写时需要满足以下规则：

- 不能为空。
- 不能与已有项目编号重复。
- 比较编号时会忽略首尾空格和大小写。

## 查找项目

在项目列表上方输入项目名称或编号即可筛选。列表较长时，可以调整每页显示数量并使用分页导航。

## 编辑项目

点击项目行右侧的 **编辑**，可以调整项目名称、编号和模块信息。

由 UniPortal 同步的项目属于外部数据，只能查看和进入，不能在当前应用内编辑或删除。

## 删除项目

本地项目可以通过项目行右侧的 **删除** 操作移除。删除前系统会要求再次确认。

::: warning
删除操作无法恢复。确认项目信息和相关报告不再需要后再执行。
:::

## 最近访问

进入项目后，该项目会出现在主页左侧的 **最近访问** 区域，便于快速返回常用项目。
