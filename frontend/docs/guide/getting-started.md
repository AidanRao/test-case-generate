# 快速开始

本文介绍从系统配置到生成第一批测试用例的基本流程。

## 1. 配置 AI 服务

首次使用前，在主页右上角进入 **系统设置**，填写用于生成测试用例的 AI 服务信息：

- **Base URL**：兼容 OpenAI 接口格式的服务地址。
- **API Key**：服务访问密钥。
- **Model**：用于生成测试用例的模型名称。

填写完成后，先点击 **测试前端与后端连接**。两端均连接成功后，再保存设置。

::: tip
前端测试由浏览器直接访问 AI 服务，后端测试由应用服务器发起。两项结果可以帮助判断网络或跨域配置问题。
:::

## 2. 创建项目

回到主页，在左侧快捷操作中点击 **新建项目**：

1. 填写项目名称和唯一的项目编号。
2. 添加一级功能模块。
3. 为模块补充结构化需求。
4. 确认信息并创建项目。

创建完成后，项目会显示在主页的项目列表中。

## 3. 进入项目

在项目列表中点击 **进入项目**。项目页面集中展示需求、测试用例和覆盖情况，你可以：

- 查看不同模块下的需求。
- 为单条需求生成测试用例。
- 查看和编辑已经生成的用例。
- 重新计算需求覆盖率。
- 导出项目测试用例。

## 4. 生成与检查用例

选择一条需求并发起生成。生成任务在后台运行，完成后会自动更新对应需求下的测试用例。

生成后建议重点检查：

- 场景是否覆盖正常、异常和边界情况。
- 前置条件与测试步骤是否可以执行。
- 预期结果是否清晰、可验证。
- 优先级和用例类型是否符合项目约定。

下一步可以阅读[需求与测试用例](/guide/requirements-and-testcases)，了解日常维护方式。
