# 系统设置

在主页右上角点击 **系统设置**，可以管理 AI 服务连接和后台定时任务。

## LLM API 设置

系统使用兼容 OpenAI 接口格式的服务生成测试用例。

| 字段 | 说明 |
| --- | --- |
| Base URL | AI 服务的接口基础地址 |
| API Key | 调用服务所需的访问密钥 |
| Model | 生成任务使用的模型名称 |

修改配置后，建议先执行连接测试，再点击 **保存设置**。

## 连接测试

连接测试会同时检查两条链路：

- 浏览器到 AI 服务。
- 应用后端到 AI 服务。

如果只有一端失败，可以根据测试结果中的 HTTP 状态、耗时和详细信息检查网络、跨域、代理或服务端访问权限。

## 系统定时任务

定时任务区域用于管理后台同步任务。你可以：

- 启用或停用任务。
- 调整执行间隔。
- 修改任务参数。
- 手动立即执行一次任务。

任务参数使用 JSON 对象格式。保存前请确认内容是合法 JSON，并符合对应任务的参数约定。
