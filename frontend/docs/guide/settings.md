# 系统设置

在主页右上角点击 **系统设置**，可以管理 AI 服务连接和后台定时任务。

## LLM API 设置

系统使用兼容 OpenAI 接口格式的服务生成测试用例。

| 字段 | 说明 |
| --- | --- |
| Base URL | AI 服务的接口基础地址 |
| API Key | 调用服务所需的访问密钥；已设置时显示固定星号，不返回原始密钥 |
| Model | 生成任务使用的模型名称 |

修改配置后，建议先执行连接测试，再点击 **保存设置**。

API Key 留空会保留已保存的密钥；输入新密钥后保存即可替换。连接测试使用新输入的密钥，未输入时由后端读取已保存的密钥，测试本身不会保存配置。

需要删除已保存的密钥时，点击 API Key 旁的 **清空密钥**，再点击 **保存设置**。保存前可点击 **撤销清空** 取消；待清空状态下执行连接测试不会使用密钥，也不会提前删除已保存的密钥。

## 连接测试

连接测试仅由应用后端请求 AI 服务，浏览器只发起测试并展示结果，不直接连接 AI 服务。

如果连接失败，可以根据测试结果中的 HTTP 状态、耗时和提示检查后端网络、代理或服务端访问权限。为避免密钥泄漏，测试结果不返回 AI 服务的原始响应内容。

## 系统定时任务

定时任务区域用于管理后台同步任务。你可以：

- 启用或停用任务。
- 调整执行间隔。
- 修改任务参数。
- 手动立即执行一次任务。

任务参数使用 JSON 对象格式。保存前请确认内容是合法 JSON，并符合对应任务的参数约定。
